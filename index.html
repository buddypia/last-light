野営の手引き

 DAY 01 / 濡れた手帳の最初の頁

まずは、一本の斧を。

あなたは調査員ミオ。嵐で船から投げ出され、グレイウォーター島へ流れ着いた。
仲間は沖で救難信号を待っている。丘の無線塔に、もう一度声を戻そう。

01 / 集める

地面の枝・小石・草に近づき E。最初は道具不要。

02 / 作る

木材3・石3・繊維2を集め、C で石斧を製作。

03 / 備える

次は槍・松明・焚き火。J のクエストで順に進める。

素材の見た目と採り方は、製作画面に図解があります。
困ったら H の手引きへ。手帳を開いている間、時間は止まります。

ABOUT & CREDITS

LAST LIGHT — 最後の灯

嵐は、すべてを奪った。それでも、この島には帰る道がある。

グレイウォーター島に取り残された調査員ミオとなり、島に残された資源を集めて道具や野営地を作り、3つの無線部品を回収して救助信号を送る一人称3Dサバイバルゲームです。

主な操作方法

WASD 移動
Shift 走る / Space 跳ぶ
マウス 視点移動
左クリック 攻撃 / 建築設置
E 採集 / 調べる / 調理 / 休息
1 / 2 / 3 石斧 / 狩猟槍 / 松明
Q / F 食料を食べる / 水筒から飲む
C 製作（作業台不要）
J クエスト手帳
M 島の地図 / Tab 持ち物
H 生存の手引き / Esc ポーズ

技術仕様と特徴

  • 100% プロシージャル生成: 3Dモデル・地形・天候・関節アニメーションは Three.js のコード、環境音・効果音は Web Audio API のシンセサイザー合成で生成。外部の3Dモデルや音源ファイルへの依存はありません。
  • オフライン & プライバシー保護: 外部サーバーとの通信・テレメトリ・トラッキングは一切ありません。ゲーム進行と設定はブラウザの localStorage にのみ保存されます。
